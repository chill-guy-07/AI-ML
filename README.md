# AI-ML

Learning projects built from scratch.

- **micrograd.ipynb** — a tiny scalar-valued autograd engine with backpropagation and a small neural net built on top of it.
- **GPT_Replica.ipynb** — a character-level GPT (decoder-only Transformer) trained on the Tiny Shakespeare dataset.
- **input.txt** — the Tiny Shakespeare dataset used by the GPT notebook.
